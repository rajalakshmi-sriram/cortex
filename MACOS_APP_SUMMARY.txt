================================================================================
                        SECURITY & CODE SIGNING
================================================================================

CERTIFICATE TYPES:

1. Self-Signed (No Cost, Users See Warning)
   └── Users can still run app
   └── Requires "Open anyway" on first launch

2. Developer ID (Free with Developer Account)
   └── No security warnings
   └── Recommended for direct distribution

3. App Store Certificate (Required for Mac App Store)
   └── Required for App Store submission
   └── Provided by Apple during account setup

CODE SIGNING PROCESS:

1. Get Certificate
   security find-identity -v -p codesigning

2. Sign App
   codesign --deep --force --sign "CERT_ID" dist/Cortex.app

3. Verify Signature
   codesign --verify --verbose dist/Cortex.app

NOTARIZATION (macOS 10.15+):

For apps outside Mac App Store:
1. Upload app to Apple notarization service
2. Apple scans for malware
3. Staple ticket to app
4. Users see no security warnings

Command:
   xcrun altool --notarize-app --file dist/Cortex.dmg ...
   xcrun stapler staple dist/Cortex.app

================================================================================
                        TROUBLESHOOTING
================================================================================

ISSUE: App won't build
FIX:
  1. Remove old build: rm -rf build dist venv-build
  2. Check Python: python3 --version (need 3.8+)
  3. Clear pip cache: pip cache purge
  4. Rebuild: ./build_macos_app.sh

ISSUE: App launches but GUI doesn't appear
FIX:
  1. Check logs: log stream --predicate 'processImagePath contains "Cortex"'
  2. Verify PyQt6: pip list | grep PyQt6
  3. Reinstall GUI: pip install --force-reinstall PyQt6

ISSUE: Server won't start
FIX:
  1. Check port: lsof -i :5000
  2. Kill old process: killall -9 python
  3. Start manually: python run.py
  4. Check Flask: python -c "import flask; print(flask.__version__)"

ISSUE: DMG creation fails
FIX:
  1. Ensure disk space: df -h
  2. Check permissions: chmod +x build_macos_app.sh
  3. Use alternative: zip -r dist/Cortex-1.0.0.zip dist/Cortex.app

ISSUE: App won't install from DMG
FIX:
  1. Check file size: ls -lh dist/Cortex-1.0.0.dmg
  2. Verify DMG: hdiutil verify dist/Cortex-1.0.0.dmg
  3. Create new DMG: ./build_macos_app.sh (rebuilds DMG)
